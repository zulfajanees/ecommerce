# ShopEase eCommerce Website

A responsive eCommerce website starter built with HTML, CSS, and JavaScript.

## Features

- Product catalog with cards and pricing
- Category filter and live product search
- Shopping cart drawer with quantity controls
- Cart persistence using browser localStorage
- Mock checkout flow
- Newsletter subscription form

## Run locally

Because this is a static site, open `src/index.html` directly in your browser.

If you prefer using a local server:

1. Open a terminal in this folder.
2. Run:
   - `python -m http.server 5500`
3. Visit `http://localhost:5500/src/`
